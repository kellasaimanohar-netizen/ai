# Data Retention Policy

All customer interactions and associated PII processed by this agent are subject to strict retention policies.

- **Conversation Logs**: Retained for 30 days for quality assurance, then automatically purged.
- **Customer Profiles**: Stored only in the master database. This agent caches no user profiles locally.
- **Analytics Data**: Anonymized immediately; no raw PII is retained in analytical data stores.

Reference: DPDP S.8(7)
